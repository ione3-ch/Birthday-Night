# Birthday Night

Ритм-игра для телефона: режь неоновые кубы в такт музыке, танцуй за одного из четырёх друзей и не зли диджея.

**Как играть:** свайп в сторону стрелки на кубе, по кубу без стрелки — тап. На компьютере можно водить мышью.

**Запуск:** откройте `index.html` через любой веб-сервер (например, GitHub Pages). На iPhone: Safari → «Поделиться» → «На экран „Домой“» — игра откроется на весь экран со своей иконкой.

Структура:
- `index.html` — вся игра
- `img/` — фон клуба, диджей, логотип, иконки
- `sprites/` — анимации персонажей
- `music/` — треки уровней
